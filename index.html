BEFORE YOU HIT SEND

A few good questions.

Will you change anything on my live website?

The free audit uses public-page checks. It does not place orders, submit contact forms or change application code. Interactive testing requires agreed scenarios and suitable test accounts.

What does “self-healing” mean?

If a selector changes, the engine can try an approved equivalent. It never removes an expected result to hide a defect, and it does not automatically fix your application code.

Does a passing report mean my website has no bugs?

No. It means the configured checks passed at the recorded time. Each report states its coverage and limitations. Manual review and broader testing remain valuable.

Where does my audit request go?

This form sends your website URL, email, selected plan and testing permission to our Vercel automation API. Your mapping is stored in a private GitHub repository.
